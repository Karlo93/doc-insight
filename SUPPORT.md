# Support

For setup and operation, start with the [README](README.md) and
[documentation index](docs/README.md). Check the [known capacity limits](benchmark/README.md)
before reporting a performance problem.

Use a bug report for reproducible failures and a task issue for proposed changes.
Include the commit or image tag, expected and actual behavior, and a minimal example
using generated documents. Strip credentials, document text and private hostnames
from logs and screenshots. Security reports follow [SECURITY.md](SECURITY.md).

This project has one maintainer and no guaranteed support response time. Discuss
large changes in an issue before implementation. Keep review feedback specific,
respectful and focused on the code; harassment and disclosure of private data are
not acceptable.
